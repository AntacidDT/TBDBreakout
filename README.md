## Breakout for the TBD62003APG Board
This board is licensed CERN-OHL-S, and is meant to be a breakout PCB board for
the TBD62003APG to 28BYJ-48 stepper motor.

## License
This board may be used freely, but if distributed or modified it should be licensed as CERN-OHL-S aswell.
You should've been given a copy of the [License](LICENSE.txt) with this repository.

## Why did I make this
I made this because even tho the ULN2003A Breakout PCB's are good, the TBD62003APG is a
lot more efficient, thus I figured a breakout made for TBD62003APG could be very useful for everyone.

## Where to get the PCB gerbers
A Zip folder is found at [/pcbgerbers/tbd62003apg_gerbers.zip](/pcbgerbers/tbd62003apg_gerbers.zip), and if you want the raw PCB gerber files, its found at [/pcbgerbers/rawpcbgerbers](/pcbgerbers/rawpcbgerbers/). The PCB gerbers use Protel Filenames because many PCB manufacturers recommend and highly prefer Protel Filename Extensions instead.
